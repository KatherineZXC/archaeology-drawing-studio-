# 器绘 · 考古绘图工作台

面向考古器物绘图整理的浏览器工具：将一张图纸中的多件器物裁剪为单件图，校对文字说明、校准比例尺，并导出 PSD 或 JPG。

## 主要功能

- 导入 PSD、PNG、JPG；PSD 文件大小上限为 500 MiB，实际处理能力取决于设备内存。
- 支持平剖面分开、平剖面合一两类图纸，提供自动建议框、手动框选、合并与拆分。
- PSD 按原像素裁剪，使用统一裁剪坐标保留可读取的栅格图层及其相对位置；米格纸可以隐藏并保留。
- 从说明区域进行 OCR 辅助识别，提供预处理预览、置信度提示及人工校对；也可直接输入说明。
- 以米格纸粗线之间一大格为 1 cm 校准比例尺。
- 导出单件 PSD、JPG，或批量 ZIP；支持仅裁剪和添加文字、比例尺两种输出方式。
- 新增 PSD 说明为可编辑文字，中文及带圈数字使用宋体，拉丁文字使用 Times New Roman。内置 `2026GSIA2` 和尺寸填写模板，可自行修改。

## 本地运行

需要 Node.js 22 或更新版本，以及 pnpm。下载源码 ZIP 并解压，在项目目录执行：

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm start
```

服务启动后，在启动该服务的这台电脑上打开 `http://127.0.0.1:4175/`；保持终端开启，按 Ctrl+C 停止服务。此地址只指向本机，不能分享给其他人打开。不要直接双击 HTML 文件。也可以使用 `npm install`、`npm run build`、`npm start`，但 pnpm 锁文件提供更可重复的依赖版本。

启动服务只监听本机。源码仓库不包含 Node.js、依赖目录或 OCR 模型；首次安装和 OCR 模型加载需要联网。构建产物在 `dist/`，可由支持 JavaScript 模块、Web Worker 和 WASM 的静态服务器托管。

## 使用步骤

1. 导入图纸，选择米格纸 / 说明所在图层。
2. 设置器物数量和平剖面关系，生成建议框，并逐件检查全部视图和剖线是否归入正确器物。
3. 框选说明区域，运行 OCR 或手动填写文字；核对编号、尺寸及单位。
4. 如需添加比例尺，选择相邻粗线校准 1 cm。
5. 核对图层和裁剪范围、勾选确认，导出 PSD 或 JPG。

## 当前限制

- 这是实验性工具，自动分组和手写 OCR 可能出错，必须人工核对；OCR 的完整端到端识别效果尚未完成验证。
- PSD 读取支持 RGB、8 位/通道，暂不支持 PSB；图纸上限为 2 亿像素，单件裁剪和批量打包也有内存保护限制。
- 此工具不是完整 Photoshop 编辑器。复杂图层组、蒙版、智能对象、调整图层及特殊混合效果不保证完整还原；请保留原文件并在 Photoshop 中检查导出结果。
- 大图预览可能降采样，PSD 导出从原始图层重新读取裁剪区域。JPG 保持输出像素尺寸并使用最高质量，但 JPG 本身仍是有损格式。
- PaddleOCR 和 Tesseract 可能联网下载模型、语言或运行资源；当前版本不保证完全离线。应用代码不主动上传用户导入的图纸。
- 宋体和 Times New Roman 依赖设备上的字体；未安装时预览可能回退，Photoshop 也可能提示缺少字体。
- 当前编辑状态不会自动保存，关闭页面前请导出结果。

## 开发与测试

```sh
pnpm test
```

测试使用程序生成的图层验证裁剪像素、图层偏移与 PSD 导出回读，不依赖真实考古资料。默认演示图也是虚构示意图，不代表真实出土器物。

主要文件：`src.js`（界面与流程）、`psd-stream.js` / `psd-worker.js`（PSD 读取）、`crop-geometry.js`（裁剪坐标）、`analysis.js`（建议范围）、`text-layout.js`（文字排版）。
